### 🛡️ About Me

I'm an offensive security professional focused on **Red Teaming** and **Penetration Testing**. With CEH certification and years of hands-on experience, I specialize in full attack lifecycle simulations: reconnaissance, initial access, execution, persistence, privilege escalation, lateral movement, and exfiltration.

What sets me apart: **Deep expertise in integrating AI/ML** into pentesting workflows. I use large language models, custom scripts, generative AI for payload crafting, anomaly detection evasion, automated vulnerability chaining, and even AI red teaming against ML-based defenses.

- 🔴 Ethical hacking only — all work in authorized environments/labs.
- 🧠 AI-augmented attacks: faster recon, smarter fuzzing, adversarial examples against AI security tools.
- 💻 Tools: Kali Linux, Metasploit, Burp Suite, Nmap, BloodHound, Cobalt Strike (in labs), custom Python/Go scripts + AI frameworks (e.g., LangChain, PyTorch for custom models).
